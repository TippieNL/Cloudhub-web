========================
FEATURE 1: IMAGE THUMBNAILS
========================

Goal:
Display thumbnail previews for image files instead of generic file icons.

Requirements:
- Supported image types: .jpg, .jpeg, .png, .webp, .gif
- Thumbnails must maintain aspect ratio
- Max size: 300x300
- Use a lightweight image library (e.g., sharp)
- Generate thumbnails dynamically
- Cache thumbnails in:
  /storage/.thumbnails/
- Naming format:
  originalFileName_hash_thumb.webp
- Thumbnail should only generate once unless file changes
- Prevent path traversal attacks
- Restrict to ROOT_DIR only

Create route:
GET /thumbnail?path=/example/image.jpg

This route must:
- Validate and sanitize path
- Confirm file exists inside ROOT_DIR
- Only allow image types
- Generate thumbnail if not cached
- Stream thumbnail safely
- Never expose absolute paths

Frontend:
- Replace image icon with thumbnail preview

- Lazy-load thumbnails
- Show loading placeholder
- Keep responsive layout

========================
FEATURE 2: SECURE SHAREABLE URLs
========================

Goal:
Allow any file to be shared via a secure public link without requiring login.

Functional Requirements:
- Add “Share” button next to each file
- Generate secure random token (minimum 32 bytes entropy)
- Map token to file path
- Optional expiration support (configurable)
- Share link format:
  https://your-repl.replit.app/share/<secureToken>

Create route:
GET /share/:token

This route must:
- Validate token
- Confirm file exists
- Stream file securely
- Prevent directory access
- Prevent traversal attacks
- Not expose directory structure
- Respect delete/overwrite restrictions

Security:
- Tokens must be unguessable
- Use crypto.randomBytes
- Do not expose root path
- Prevent brute force risks
- Ensure share route cannot access arbitrary files
